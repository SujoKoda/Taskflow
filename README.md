# TaskFlow

A task tracker built with React.

**Live demo:** https://sujokoda.github.io/Taskflow/

## Features
- Add tasks with a priority level (High, Medium, Low) and an optional due date
- Mark tasks complete or delete them
- Filter by All, Active, or Done, and clear completed tasks in one click
- Tasks sort automatically: unfinished first, then by priority
- Overdue tasks are flagged
- Tasks save to localStorage, so your list persists between visits
- Light and dark mode follow your system setting

## Tech
- React 18 (functional components and hooks: useState, useEffect, useMemo)
- JavaScript, HTML, CSS
- Hosted on GitHub Pages

## Run it locally
Download `index.html` and open it in a browser. No install needed.
